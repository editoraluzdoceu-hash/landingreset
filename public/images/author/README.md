# Foto do autor

Esta pasta guarda o retrato exibido na seção **"Quem criou"** (`#autor`).

## Como adicionar a foto

1. Salve o arquivo nesta pasta com o nome **`lucas.jpg`** (ou `.webp` / `.png`).
2. Formato recomendado: retrato vertical na proporção **4:5** (ex.: 600×750px ou 1200×1500px).
3. Se usar um nome ou formato diferente, atualize o caminho em
   `src/data/content.ts` → `founder.photo.src`.

Enquanto nenhum arquivo existir, o site exibe automaticamente um espaço
reservado elegante com a inicial do nome — nada quebra.
